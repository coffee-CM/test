Motion 핵심 기능 간단 데모

웹 표준 기반의 가볍고 강력한 애니메이션 라이브러리 motion 예제입니다.

1 스프링 바운스 (클릭)

부드러운 스프링 물리 기반 회전 및 스케일

클릭해보기 Click!
easing: spring(0.8, 0.5) 클릭: 0회

2 순차 등장 (Stagger)

지연 시간(delay)을 두고 카드가 차례로 팝업

⚡ Fast
✨ Smooth
🪶 Light
delay: stagger(0.12)

💡 간단 코드 미리보기

JavaScript / HTML 에서 쓸 때:

import { animate, spring } from "motion";

// 1. 단일 요소 애니메이션
animate("#box", { rotate: 360, scale: [1, 1.2, 1] }, {
  easing: spring(0.8, 0.4)
});

// 2. 여러 요소 순차 등장 (Stagger)
import { stagger } from "motion";
animate(".cards", { opacity: [0, 1], y: [20, 0] }, {
  delay: stagger(0.1)
});

React 에서 쓸 때 (motion/react):

import { motion } from "motion/react";

export default function Box() {
  return (
    <motion.div
      initial={{ opacity: 0, scale: 0.8 }}
      animate={{ opacity: 1, scale: 1 }}
      whileHover={{ scale: 1.1 }}
      whileTap={{ scale: 0.95 }}
      transition={{ type: "spring", stiffness: 400, damping: 17 }}
    >
      클릭!
    </motion.div>
  );
}
